CONCEPTO 06

Pip

Una boca que enseña a pronunciar.

  • Su boca muestra cómo articular: la lengua entre los dientes para /θ/, el labio para /v/.
  • En el drill, Pip modela el sonido mientras lo escuchas.
  • Riesgo: una boca tan protagonista puede verse rara si no se cuida el estilo.
