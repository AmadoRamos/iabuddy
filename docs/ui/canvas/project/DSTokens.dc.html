Tokens semánticos y tipografía responsive

Los componentes nunca usan un hex directo: usan estos tokens. Así un cambio de color se hace en un solo lugar.

Estados semánticos

fondo · texto (≥ 4,5:1) · sólido · borde (≥ 3:1)
ESTADO-BG-FG-SOLID-BORDEREJEMPLOUSO --success #EEFAD9 #2F5208 #9BE22D #4D7C0F Guardado Aciertos, logros, campo válido, modelo listo. --warning #FFF4C7 #854D0E #FFC800 #A16207 Tarda más Racha en peligro, latencia alta, «casi» (70–84). --error #FFE8DF #9A3412 #FF6B3D #D9480F Revisa el campo Validación y fallos técnicos. Errores de inglés: «a practicar». --info #E3E8FF #2338C9 #3D5AFE #3D5AFE Consejo Consejos, ayuda, correcciones de gramática.
Los sólidos (lima, amarillo, coral) son de 1,5 a 2,8:1 sobre blanco: se usan como relleno con texto tinta encima, nunca como texto ni como único borde. Cada estado lleva siempre su ícono.

Movimiento y preferencias

--dur-fast150 ms · hover, presionado --dur-base250 ms · modales, tooltips, toasts --dur-slow500–900 ms · barras de progreso, celebración --ease-outcubic-bezier(.2, .8, .2, 1) --ease-popcubic-bezier(.3, 1.5, .5, 1) · rebote suave 
@media (prefers-reduced-motion: reduce) {
  :root { --dur-fast: 0ms; --dur-base: 0ms; --dur-slow: 0ms; }
  .onda * { animation: none; }  /* el estado queda en texto */
}
[data-motion="reduced"] { /* misma regla, desde Ajustes */ }
Ajustes añade «Animaciones: automáticas / reducidas», por si el sistema no lo indica.
