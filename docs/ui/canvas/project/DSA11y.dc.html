El color nunca va solo

think 62 a practicar
  • Puntuaciones: color + cifra + palabra («a practicar»).
  • Correcciones: tachado y resaltado, además del color.
  • Calendario: punteado = protector, borde grueso = hoy, y etiqueta accesible por día.
  • Gravedad: barras de 1 a 3 + texto BAJA, MEDIA, ALTA.

Lectores de pantalla

  • El estado de Onda se anuncia en una región aria-live="polite": «Te escucho», «Pensando», «Buddy está hablando».
  • La transcripción es un role="log"; cada turno nuevo se lee una vez.
  • Todo texto en inglés lleva lang="en", para que el lector cambie de voz.
  • Botones de ícono con aria-label; SVG decorativos con aria-hidden.

Movimiento y tiempo

  • Con prefers-reduced-motion se detienen ondas, anillos y confeti; el estado sigue indicado con texto.
  • Nada parpadea más de 3 veces por segundo.
  • Silencio de fin de turno ajustable (0,4–2 s) para quien necesita más tiempo para pensar.
  • Los escenarios no cortan de golpe: el límite de minutos solo sugiere cerrar.

Audio con texto

Todo lo que dice Buddy aparece como texto en la conversación y se puede volver a escuchar. Velocidad de voz ajustable (0,8×–1,1×).

Texto ampliado

Las pantallas son fluidas: al 200 % de zoom las columnas pasan a una sola y no hay scroll horizontal. Texto de cuerpo mínimo 14 px.

Tono sin culpa

La XP nunca resta y los errores se presentan como «a practicar». El rojo de alarma no existe en la paleta.
